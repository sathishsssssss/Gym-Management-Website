SLEEK FITNESS - COMPLETE COLLEGE PROJECT
========================================

PROJECT DESCRIPTION
-------------------
Sleek Fitness is a responsive gym management and fitness
website developed as a college web development project.

It allows users to view gym information, membership plans,
trainers, facilities, reviews and FAQs. Users can also submit
a request to book a free gym visit.

The project also includes a demo Admin Login and Admin
Dashboard.


PROJECT FILES
-------------

index.html
    Home page

plans.html
    Membership plans

trainers.html
    Trainer information

facilities.html
    Gym facilities and images

reviews.html
    Customer/member reviews

faq.html
    Frequently Asked Questions

contact.html
    Contact details and free-visit booking form

login.html
    Admin login page

admin.html
    Admin dashboard

style.css
    Website design, layout and responsive styling

script.js
    Navigation, forms, membership selection,
    admin login and logout functionality


TECHNOLOGIES USED
-----------------

HTML5
    Used to create the structure of the website.

CSS3
    Used for styling, layouts, colors, animations
    and responsive design.

JavaScript
    Used for website interactions and functionality.

LocalStorage
    Used for the demo admin login and selected
    membership plan.


IMAGES
------

The website contains 12+ gym and fitness images.

The images are loaded directly from Unsplash using
online image URLs.

Therefore, an internet connection is required
to display the images.

No separate images folder is required.

HOW TO RUN THE PROJECT
----------------------

1. Extract the ZIP file.

2. Open the "sleek-fitness" folder.

3. Make sure all files are present:

   index.html
   plans.html
   trainers.html
   facilities.html
   reviews.html
   faq.html
   contact.html
   login.html
   admin.html
   style.css
   script.js

4. Open "index.html" in Google Chrome or Microsoft Edge.

5. For better development and testing,
   open the folder in VS Code.

6. Install/use the Live Server extension.

7. Right-click index.html.

8. Select "Open with Live Server".


IMPORTANT
---------

This is a front-end college project.

The contact form does not send information
to a real server.

The admin dashboard uses browser LocalStorage.

The admin login is only for demonstration.

It does not use a real database or secure
authentication system.
