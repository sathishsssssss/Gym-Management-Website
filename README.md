# Sleek Fitness – Gym Management Website

## About the Project

Sleek Fitness is a modern gym management website designed to provide
an attractive and user-friendly platform for managing gym-related
services, memberships, trainers and fitness activities.

## Features

- Modern and responsive UI
- Gym membership information
- Trainer information
- Fitness services
- Contact section
- Responsive design
- User-friendly navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript
